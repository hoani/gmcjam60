Break an Egg
    by Hoani Bryson


This game is about breaking an egg

But more importantly, it is about stopping other people from breaking eggs

You can make your own level and share it with everyone else in the lobby - alternatively, you can play other's levels and break thier eggs!

For anyone who would prefer to play in the browser: 
https://gx.games/games/2ofnl6/break-an-egg/tracks/c306cee3-e075-4180-9f43-4120254169a6/

Controls
    Mouse does everything:
        - Left click: place things
        - Right click: delete things
        - Scroll: change item

Confessions of a Code Reuser

    I reused a bunch of UI, geometry, and some physics code from other projects I have made.

    This game built off some of "Throw a Watermelon". But to be honest, most of the physics
    and builder stuff was rebuilt from scratch, because Throw a Watermelon was quite rigid
    in how it handled user interactions/joins and so on...
